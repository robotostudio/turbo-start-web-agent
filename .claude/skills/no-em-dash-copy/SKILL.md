# No em dashes in site copy

Never use the em dash character (—) in copy or other user-facing prose for this site. Use commas, colons, semicolons, parentheses, or full stops instead.

Before delivering copy, search the changed text for em dashes, en dashes, spaced dashes, and double hyphens used as dashes. Rewrite each one naturally rather than replacing punctuation mechanically.

Apply this rule to page content, UI labels, metadata, announcements, blog posts, documentation, pull request text, and commit messages. Keep punctuation readable and consistent with the surrounding voice.

This is a site-wide convention, not a personal preference. It lives in the repository so every contributor and content-editing agent applies the same copy rule.
