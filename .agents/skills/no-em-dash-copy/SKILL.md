# No em dashes in visitor-facing copy

Never use the em dash character (—) in copy visitors read on this site. Use commas, colons, semicolons, parentheses, or full stops instead.

Apply this rule to page content, UI labels, metadata, announcements, and blog posts. Before delivering any of those, search the changed text for em dashes, en dashes, spaced dashes, and double hyphens used as dashes. Rewrite each one naturally rather than replacing punctuation mechanically.

This rule does not apply to the repository's own documentation, commit messages, or pull request text. Those may continue to use em dashes.

This is a site-wide convention for visitor-facing copy, not a personal preference. It lives in the repository so every contributor and content-editing agent applies the same rule.
