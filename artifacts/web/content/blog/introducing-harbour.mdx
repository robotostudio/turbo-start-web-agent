excerpt: Why we built a marketing-site starter that any AI agent can edit safely.
---

Harbour is a starting point for marketing sites that a non-technical team can
edit through an AI agent, while developers keep working locally in git.

The trick is that content is code-free by construction, so an agent editing a
page cannot reach past the page.
